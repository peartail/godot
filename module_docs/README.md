# Module Docs

Godot engine module documentation and planning notes are grouped by feature.

## World Placement

- `world_placement/`: Independent region populate / area-replacement domain (presets, runtime contract, surface backends). Not a sub-feature of any terrain module.

## OpenWorldTerrain

- `open_world_terrain/`: GPU displacement terrain module architecture and next-step planning.

## SimpleTerrain

- `simple_terrain/`: SimpleTerrain runtime, editor, generator, material, navigation, and integration docs. Includes scene-profile placement editor notes; see also `world_placement/` for the shared domain framing.

## SplineMesh3D

- `spline_mesh_3d/`: SplineMesh3D module/spec notes.
