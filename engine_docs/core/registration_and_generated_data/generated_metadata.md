# Generated Metadata

## Scope

Generated author, donor, license, version, disabled-class, and script encryption key data.

## Entry Points

- `authors.gen.h`
- `donors.gen.h`
- `license.gen.h`
- `version_generated.gen.h`
- `version_hash.gen.cpp`
- `disabled_classes.gen.h`

## Flow Notes

- Generated metadata is produced by build-time scripts and should not be edited by hand.
- Version and hash data are used by startup, diagnostics, and extension/API reporting.
- Disabled class metadata affects registration and exposed API surface.
