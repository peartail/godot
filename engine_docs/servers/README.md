# Servers

Low-level runtime servers that expose engine subsystems behind stable APIs.

## Subtopics

- Rendering server and rendering device
- Physics server 2D and 3D
- Audio server and audio effects
- Navigation server
- Text server and font shaping
- Display, input, camera, and XR server interfaces
