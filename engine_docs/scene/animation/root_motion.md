# Root Motion

## Scope

Root motion visualization and AnimationTree root motion extraction support.

## Entry Points

- `RootMotionView`
- `AnimationTree`

## Flow Notes

- Root motion data is extracted from animation tracks during animation tree evaluation.
- RootMotionView helps visualize extracted motion in 3D scenes.
