# Lists Trees Graphs

## Scope

Item lists, tree controls, graph edit surfaces, graph nodes, graph elements, frames, and graph layout arrangement.

## Entry Points

- `ItemList`
- `Tree`
- `GraphEdit`
- `GraphNode`
- `GraphElement`
- `GraphFrame`
- `GraphEditArranger`

## Flow Notes

- List/tree controls own custom item models and drawing/input behavior.
- GraphEdit manages panning, selection, connections, and graph child layout.
- Graph arrangement helpers compute layout for graph nodes and frames.
