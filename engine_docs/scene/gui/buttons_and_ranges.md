# Buttons And Ranges

## Scope

Buttons, toggles, check boxes, option/menu buttons, range base class, sliders, scroll bars, progress bars, and spin boxes.

## Entry Points

- `BaseButton`
- `Button`
- `CheckBox`
- `CheckButton`
- `OptionButton`
- `MenuButton`
- `Range`
- `Slider`
- `SpinBox`

## Flow Notes

- Button state controls pressed/hover/focus/toggle behavior and emits UI signals.
- Range synchronizes value, min/max, step, ratio, and shared ranges.
- Option/menu buttons connect to popup menu state.
