# Animation Resources

## Scope

Animation data tracks, animation libraries, skeleton profiles, bone maps, sprite frames, and animated textures.

## Entry Points

- `Animation`
- `AnimationLibrary`
- `SkeletonProfile`
- `BoneMap`
- `SpriteFrames`
- `AnimatedTexture`

## Flow Notes

- Animation resources store tracks sampled by animation player/tree systems.
- Skeleton profile and bone map resources support retargeting and skeleton workflows.
- Sprite frames and animated textures support 2D animated playback resources.
