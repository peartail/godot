# Media And Misc Resources

## Scope

Audio streams, video streams, bitmaps, palettes, text files, drawable textures, and small helper resources.

## Entry Points

- `AudioStreamWAV`
- `AudioStreamPolyphonic`
- `VideoStream`
- `BitMap`
- `ColorPalette`
- `TextFile`

## Flow Notes

- Audio/video resources are consumed by scene playback nodes.
- Bitmaps and palettes are utility resources used by tools and runtime features.
- TextFile wraps text content as a resource for loading/saving workflows.
