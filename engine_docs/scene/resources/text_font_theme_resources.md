# Text Font Theme Resources

## Scope

Fonts, text layout resources, label settings, style boxes, themes, syntax highlighting, and UI styling resources.

## Entry Points

- `Font`
- `TextLine`
- `TextParagraph`
- `LabelSettings`
- `StyleBox`
- `Theme`
- `SyntaxHighlighter`

## Flow Notes

- Font and text layout resources interact with TextServer shaping.
- Style boxes and themes are consumed by Control theme lookup.
- Label settings are shared by 2D/3D labels and UI text workflows.
