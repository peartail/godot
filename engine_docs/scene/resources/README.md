# Resources

Scene-facing resources for packed scenes, animation, textures, materials, meshes, shapes, navigation, shaders, text, theme, worlds, audio, and video.

## Subtopics

- [Packed Scene And Text Format](packed_scene_and_text_format.md): `PackedScene`, text resource format, scene state, and instancing data.
- [Animation Resources](animation_resources.md): `Animation`, libraries, skeleton profiles, bone maps, and animated textures/frames.
- [Textures And Images](textures_and_images.md): textures, image textures, compressed/portable/placeholder textures, atlases, gradients, and camera/external textures.
- [Materials And Shaders](materials_and_shaders.md): materials, canvas materials, particle process materials, shaders, shader includes, visual shaders, and skies.
- [Meshes And Geometry](meshes_and_geometry.md): meshes, primitive/importer/immediate mesh, multimesh, mesh tools, surfaces, and curves.
- [Physics Shapes](physics_shapes.md): 2D/3D shape resources and physics material.
- [Navigation Resources](navigation_resources.md): navigation mesh/polygon and source geometry data.
- [Text Font Theme Resources](text_font_theme_resources.md): fonts, text lines/paragraphs, label settings, style boxes, syntax highlighter, and theme resources.
- [World Environment Camera](world_environment_camera.md): worlds, environment, camera attributes, compositor, fog/sky resources, and rendering environment data.
- [Media And Misc Resources](media_and_misc_resources.md): audio streams, video streams, bitmaps, palettes, text files, and helper resources.
